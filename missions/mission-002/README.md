# Mission 002 — Astrobotic Griffin Mission One / FLIP

This package records Astrobotic Griffin Mission One (`M02`), also called
Griffin-1 and NASA Moon Base II. Its manifested Astrolab rover is FLIP, the
FLEX Lunar Innovation Platform. Public facts and engineering gaps are recorded
in [`mission-research.md`](mission-research.md); the executable LunCoSim Twin
is maintained in [`../../twins/astrobotic-griffin-1/`](../../twins/astrobotic-griffin-1/).

M01 remains the separate Blue Moon MK1 Endurance package. This M02 package is
an additional mission record, not a rename of the repository's first mission.

`scene.usda` composes the Twin's canonical
`scenes/griffin_1_surface_ops.usda`. Griffin and FLIP geometry, dynamics,
terrain, and mission composition are authored in the Twin; this mission
package does not keep a second vehicle or environment model.
